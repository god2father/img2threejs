# NOIR S1 音箱开发交接

更新时间：2026-07-30（Asia/Shanghai；第 04 箱体重建中）

本文只记录 NOIR S1 音箱演示。根目录的 `HANDOFF.md` 仍是透明玻璃杯演示的历史交接，不能作为音箱实现的验收依据。

## 1. 项目与本地预览

项目使用 TypeScript、Three.js 与 Vite。NOIR S1 的运行入口是 `src/main.ts`，模型实现是 `src/createSpeakerModel.ts`。

本地开发预览：

```bash
npm install
npm run dev
```

Vite 默认会使用 `http://127.0.0.1:5173/`；若该端口已被占用会自动递增。当前会话的开发页运行在 `http://127.0.0.1:4173/?explode=1`。`?explode=1` 应直接显示九个组件的爆炸状态；页面的 **EXPLODE VIEW / REASSEMBLE** 按钮是改变爆炸状态的唯一入口。

## 3. 已确认的九件拆分合同

1. 金属前网罩：深色暖铜/黄铜交织孔洞金属，带独立凸起暖金色脚本徽标。
2. 前框：薄黑色圆角皮革矩形环；连续窄暖金/黄铜内缘；中心真实透空。
3. 驱动板：黑色挡板，左右高音和中央低音为所属细节。
4. 声学腔体：黑色皮革外壳与前开口内的暖棕色 MDF 内壁、侧壁、顶/底壁及隔板分开表达。
5. 内部 PCB / 电子组件。
6. 顶部黄铜控制面板：旋钮和拨杆随面板移动。
7. 后部黄铜连接面板：接口随面板移动。
8. 黑色后盖板：提手和螺钉随盖板移动。
9. 底脚与紧固件：作为一个硬件组。

螺钉、徽标、装饰和局部细节必须属于上述某一组件，不能成为额外爆炸层。

## 8. 严格开发规则

1. **逐层工作**：一次只改用户当前指定的一件；不得顺带修改其他组件、爆炸位移、相机或灯光。
2. **以九件单件图为准**：单件图定义该层的结构、材质和附属件归属；爆炸图定义拆分关系；多视图主图定义组装外观。
3. **用户视觉验收优先**：代码存在、数据注册、内部截图或构建通过均不等于通过。默认网页中肉眼可见、与参考可比才算通过。
4. **未验收不自行推进**：默认等待当前层用户确认；用户明确指定跳到其他层时，以该直接指示为准。
5. **不要擅自拆层**：装饰、螺钉、徽标、接口和局部细节必须随所属大件移动。
6. **PBR 通道独立**：albedo、normal、roughness、metalness 必须按材质类型独立处理；不要把同一颜色图复用于所有通道。几何仍负责开孔、壁厚、边框、五金和扬声器形体。
7. **如参考不充分，明确近似**：不可用通用占位材质或猜测替代已确认的外观要求。
