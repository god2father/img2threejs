# NOIR S1 音箱开发交接

更新时间：2026-07-30（Asia/Shanghai）

本文只记录 NOIR S1 音箱演示。根目录的 `HANDOFF.md` 仍是透明玻璃杯演示的历史交接，不能作为音箱实现的验收依据。

## 1. 项目与本地预览

项目使用 TypeScript、Three.js 与 Vite。NOIR S1 的运行入口是 `src/main.ts`，模型实现是 `src/createSpeakerModel.ts`。

本地开发预览：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/?explode=1`。`?explode=1` 应直接显示九个组件的爆炸状态；页面的 **EXPLODE VIEW / REASSEMBLE** 按钮是改变爆炸状态的唯一入口。

## 3. 已确认的九件拆分合同

1. 金属前网罩：深色暖铜/黄铜交织孔洞金属，带独立凸起暖金色脚本徽标。
2. 前框：薄黑色圆角皮革矩形环；连续窄暖金/黄铜内缘；中心真实透空。
3. 驱动板：黑色挡板，左右高音和中央低音为所属细节。
4. 声学腔体：黑色皮革外壳与前开口内的暖棕色 MDF 内壁、侧壁、顶/底壁及隔板分开表达。
5. 内部 PCB / 电子组件。
6. 顶部黄铜控制面板：旋钮和拨杆随面板移动。
7. 后部黄铜连接面板：接口随面板移动。
8. 黑色后盖板：提手和螺钉随盖板移动。
9. 底脚与紧固件：作为一个硬件组。

螺钉、徽标、装饰和局部细节必须属于上述某一组件，不能成为额外爆炸层。

## 4. 已完成的结构与交互改动

### 4.1 九件结构与爆炸交互

- 旧的四层抽象 UI/爆炸逻辑已替换为以上九个可选择组件。
- 组件的爆炸位移定义在 `src/main.ts` 的 `explodeOffsets`。
- 模型或右侧组件面板的点击只负责选中/查看，不会触发爆炸或重组；只有明确的页面按钮可以改变 explode 状态。
- 第 04 声学腔体已建为前方开口的壳体，有外层黑色包覆与可见 MDF 内腔/支撑，而不是实心方块。

### 4.2 第 01 层：金属网罩（未验收，当前冻结）

- 当前状态：有独立网罩组件、深色暖金属观感和独立凸起脚本徽标；徽标不应再烘焙为阴刻文字。
- 已知缺陷：当前可见纹理仍偏横向条纹/程序化感，未达到单件图要求的细密、近不透明、暖铜深色交织金属点状编织。
- 未完成：为第 01 生成并接入真实的独立金属位图 PBR（albedo、metalness、roughness、normal），并在掠射光旋转下验证断续的编织高光。用户曾要求暂时冻结第 01；没有新的明确指示时不要继续改它。

### 4.3 第 02 层：前框（几何已修，材质待视觉验收）

- 已完成几何：使用单一连续圆角矩形环的 Shape/Extrude 拓扑，中心没有面片；不再是四根独立棍状件。
- 已完成金线：黄铜内缘为同一路径上的闭合圆角环，四角连续，不应存在端点、直角或接缝。
- 已接入皮革 PBR：`front-frame-leather_albedo.png`、`front-frame-leather_normal.png`、`front-frame-leather_roughness.png` 已分别绑定到前框 `MeshStandardMaterial` 的 `map`、`normalMap`、`roughnessMap`。albedo 为 sRGB；normal/roughness 为非颜色数据；贴图加载后会令材质 `needsUpdate`。
- 当前材质目标：近黑、微暖、低对比的荔枝纹皮革；不应是中灰塑料、织物、细砂噪点或岩石。
- 已知缺陷：尽管贴图已实际绑定，默认爆炸画面中窄框的荔枝纹可读性仍须用户视觉验收；不要把“文件存在”或“构建通过”当作第 02 已通过。

## 7. 严格开发规则

1. **逐层工作**：一次只改用户当前指定的一件；不得顺带修改其他组件、爆炸位移、相机或灯光。
2. **以九件单件图为准**：单件图定义该层的结构、材质和附属件归属；爆炸图定义拆分关系；多视图主图定义组装外观。
3. **用户视觉验收优先**：代码存在、数据注册、内部截图或构建通过均不等于通过。默认网页中肉眼可见、与参考可比才算通过。
4. **未验收不推进**：当前第 02 尚未获得用户通过，不能开始第 03。
5. **不要擅自拆层**：装饰、螺钉、徽标、接口和局部细节必须随所属大件移动。
6. **PBR 通道独立**：albedo、normal、roughness、metalness 必须按材质类型独立处理；不要把同一颜色图复用于所有通道。几何仍负责开孔、壁厚、边框、五金和扬声器形体。
7. **如参考不充分，明确近似**：不可用通用占位材质或猜测替代已确认的外观要求。

## 8. 建议下一步与验收清单

### 下一步

1. 停在第 02，打开默认 `?explode=1` 让用户检查：黑框是否近黑暖调、荔枝纹是否可辨、金线是否细且闭合、中心是否完全透空。
2. 只有用户明确通过第 02，才开始第 03 驱动板；先写出单件图中可核验的几何和材质规格，再做最小改动。
3. 每一层通过后再进入下一层；第 01 的冻结状态需要用户重新授权后再处理。

### 每层验收

- 默认爆炸页中该组件独立可读，未被附属件或其他层误遮挡。
- 组件的颜色、纹理尺度、粗糙度、金属/非金属反射、厚度和开孔与单件图一致。
- 附属件随正确的组件移动，点击组件只选中而不改变 explode 状态。
- 组装状态和爆炸状态都没有材质加载错误或多余独立层。
